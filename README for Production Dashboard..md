# Excel - Production Dashboard

 This Dashboard presents Production metrics of a Company which can be filtered using various slicers.

# Project Objectives

This Project is focused on creating a dashboard on Manager performance, Cost of Production , Units produced against time, Average production cost which can be filtered using Slicers.

# Lessons Learned

Through the completion of this project, I gained valuable insights and developed several skills, both technical and soft skills. Here's what I learned:

Technical Skills:-

Data Analysis Techniques: Utilized ETL (Extract, Transform, Load) methodology for processing data efficiently and how to clean it.

Power Query: Used Conditional Column to make a seperate column of Age Group.

Pivot Table: Incorporated supplementary data to get different insights through charts.

Formulas: used formula to make a column of cost per unit.VLOOKUP is used to correct error in ages of manager.

Filters:- Added 4 slicers of Production ID, Region, Age Groups, Quarters of year to make dashboard more dynamic.

Soft Skills:-

Systematic Approach: Developed a systematic approach to devising a report-building plan, enhancing efficiency.

Dashboard Design: Developed a understanding of data visualization.
## Data Available

Production ID
Production Date
Region- North, South, East, West
Manager of Production
Product Type - Automobiles, Electronics, Furniture, Machinery.
Units Produced
Total Cost of Production

Gender of Manager- where there were null values, it is represented as 'unknown'

Age of Manager

Age Group:- Age of Manager is grouped into A1,A2 and A3 with ages  less than 35 (as A1),between 35 to 45 (as A2) and above 45 as A3 using Conditional Column.

Production Cost per Unit: It is calculated by dividing Total Cost of Production and Units Produced using Formula.




## Key Insights 

1.) Automobiles has highest cost of production in 3D Column chart since it requires few materials to be imported like rare earth minerals.

2.) Manager Nancy Grey performed highest number of tasks. Some reward measures can be taken to increase tasks of Low Performing Managers as depicted in 3D Bar Chart.

3.)  Highest units are produced in November 2023, while production in rest of the year is cyclical as seen in 3D Line Chart.

4.) Average production cost per unit is highest in Furniture as most part is occupied in 3D Pie Chart whereas whereas Electronics and Furniture have almost equal average production cost per unit.
